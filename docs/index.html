轻酒馆不是一个社交平台，也没有账号。它只是一间你自己的酒馆： 导入一张角色卡，接上你挑的模型，然后把门关上。

它是什么

一个聊天工具，
而不是一个内容平台。

01

角色卡市场，只在应用里

逛 Chub.ai 上的公开角色卡，按热门、最新、标签、语言、长度挑。非中文的卡可以先看译文，再决定要不要下载——下载完直接进库，不用来回传文件。

成人向内容默认不显示，需要自己去设置里打开。

02

模型自己选，钱付给服务商

DeepSeek、智谱、Kimi、小米 MiMo、本地 Ollama，或者任何 OpenAI 兼容接口。上下文窗口按模型自动判断，也能手动改。没有中间层，也没有我们替你转发。

应用免费；聊天的费用由你选的模型服务商按用量收。

03

一段对话可以很长的样子

早期内容自动压成摘要、长会话增量保存、先渲染最近 200 条往上翻、搜索和统计有索引。聊到几百条也不会一卡一顿。

觉得哪句不该发给模型，就把它对模型隐藏——本机还留着，只是不带进上下文。

04

不止一条时间线

同一个角色能开多段聊天；任意一条消息都能岔出分支；书签、搜索、导出长图和 EPUB 都在菜单里。走岔了可以回头，不必重开一局。

05

酒馆生态的东西也能带进来

SillyTavern 的 V2/V3 角色卡、世界书、显示正则、预设和 .jsonl 聊天记录都能导入。世界书可以按全局、人设、角色、某段聊天分开绑定。

导入前会给你一份体检报告：哪些能用、哪些只能保留、哪些不会执行。

06

没有账号，也没有云

数据就在应用目录里。要换手机，导出一个 zip，在新机器上恢复，还能挑只恢复角色卡或只恢复设置。

备份里含 API Key，注意别随手发出去。

怎么开始

三步，大约两分钟。

  1. 1

    装上

    下载 APK 安装。第一次装需要允许「安装未知来源应用」；之后有新版本，应用里会提示更新。

  2. 2

    接一个模型

    跟着引导挑服务商，去官网拿 API Key，粘回来点「测试连接」。填错了会告诉你大概是哪一步的问题。

  3. 3

    请一个角色进来

    从市场挑一张，或者导入手机里的 .png / .json / .charx。点开角色，说第一句话。

不想按顺序来也没关系，跳过引导，进设置里慢慢配。

问题

你可能想先知道这些。

要花钱吗？

应用本身免费、开源，MIT 协议。聊天要调用模型，费用由模型服务商按 token 收；有些服务商有免费额度，本地跑 Ollama 则完全不用钱。

聊天记录会被谁看到？

这个项目没有服务器，也没有账号。记录存在手机里。你发出去的对话内容会按需发送给你选择的模型服务商——仅此而已。

能直接导入 SillyTavern 的角色卡吗？

可以。V2/V3 角色卡（.png、.json、.charx）、世界书、显示正则、预设、.jsonl 聊天记录都支持；预设里的提示词顺序可以在「兼容模式」里真正生效。

换手机怎么办？

设置 → 帮助与关于 → 备份与恢复，导出 zip。新手机上选「从备份恢复」，可以只恢复角色卡、只恢复聊天，或者只恢复设置。

支持哪些手机？

Android 7.0 及以上（minSdk 24）的 arm64 设备。平板能装，但界面是按手机排的。

为什么商店里搜不到？

因为它不上架应用商店：没有账号体系、没有内容审核，也不适合商店的分发规则。安装包直接放在 GitHub Releases。
