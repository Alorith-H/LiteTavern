02 — THE IDEA

不是另一个社交平台。
是你自己的故事空间。

没有信息流，也不需要经营账号。角色、对话和偏好都保存在设备本地；和谁说话、用哪个模型、故事往哪走，都由你决定。

工具应该退后一步。
让故事站到前面。

从打开应用到进入对话，界面尽量保持干净。复杂的能力仍然在，只在你需要的时候出现。它不替你决定剧情，也不替你选模型。

03 — CAPABILITIES

Everything you need.
Nothing in your way.

功能围绕角色聊天的真实用法组织：导入、连接、阅读、管理与备份。常用的事保持简单，进阶的选项也都留着。

01 / CHARACTERS
↗

角色卡与市场

导入 PNG、JSON、CHARX 角色卡；内置角色市场可以浏览、筛选、下载，非中文卡还能一键翻译成中文。

02 / PROVIDERS
↗

接上自己的模型

内置常见服务商预设，也支持任意 OpenAI 兼容接口；一键拉取模型列表，上下文长度按模型自动判断。

03 / LONG CHATS
↗

长对话也能继续

自动摘要压缩早期剧情，输入框上方实时显示上下文占用；会话按需分页，聊到很后面也不卡。

04 / BRANCHING
↗

分支与多会话

同一个角色可以开多条会话，也能从任意一条消息分叉出另一条故事线，不必覆盖原来的走向。

05 / WORLDBOOK
↗

世界书与提示词

世界书支持按全局、角色、会话、人设四种范围挂载；提示词检视会逐段标出 token 与缓存断点。

06 / LOCAL DATA
↗

本地优先

对话、角色与设置都在本机；整库备份能导出成 zip，换设备时挑要恢复的内容即可。

04 — GET STARTED

从安装到第一句话。
只要三步。

准备好模型服务商给的 API 信息，或者接一个本地模型；再带一张角色卡进来就行了。

STEP 01 / INSTALL

安装应用

点页面上的下载按钮就能直接拿到 APK，会自动挑最快的源。第一次更新时系统会要求允许「安装未知应用」，应用里会直接带你去打开。

↘
STEP 02 / CONNECT

连接模型

选择服务商，填 API 地址、密钥和模型名，点「获取模型列表」就能选好模型并测试连接。

⌁
STEP 03 / IMPORT

导入角色

导入本地角色卡，或者去角色市场挑一个；也可以直接建个空白角色，从第一句话开始。

＋
05 — THE EXPERIENCE

对话方式，由你决定。

同一段故事，可以用熟悉的聊天气泡看，也可以切成更适合长篇阅读的连续排版。界面服务于内容，而不是反过来。

06 — FAQ

A few things
worth knowing.

关于费用、数据和更新方式的简短说明。

应用本身开源免费。用云端模型时，费用由模型服务商按调用量收取；也有服务商提供免费模型，或者可以在设置里接一个本地模型。
对话保存在本机。只有发送消息时，内容才会按你的配置发给你选择的模型服务商，具体怎么处理取决于那家的隐私政策。
可以导入 SillyTavern 的常见格式，比如 PNG、JSON、CHARX；世界书、预设、正则和聊天记录也做了兼容。带扩展脚本的角色卡会提示可能不完整，建议先留一份原文件。
用「备份与恢复」把整库导出成一个 zip，在新设备上选择要恢复的内容（角色、会话、世界书、分组、设置）即可。备份里可能含 API 密钥，请自己收好。
应用内更新会先测速，在 GitHub 和几个加速镜像之间自动挑最快的，还支持断点续传；第一次安装时按提示打开「允许安装未知应用」就行了。也可以在「设置 → 帮助与关于 → 更新下载源」里填自己的加速地址。

网页这边同理：点下载按钮会先测速再挑源，下不动就换下一个；页面底部也列了每个源，可以自己点。
点页面上的下载按钮就可以了，会直接开始下载 APK，不用先打开 GitHub 页面。

想手动选源的话：
· GitHub 直连
· 加速镜像 ghfast
· 加速镜像 gh-proxy
· 加速镜像 ghproxy.imciel
· 加速镜像 ghproxy.net

历史版本和更新说明在 Releases 页面；加速镜像属于第三方服务，偶尔会失效，失效就换一个。
