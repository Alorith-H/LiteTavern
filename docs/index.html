它做什么

角色卡市场

直接在应用里逛公开角色卡，按热门、最新、标签、语言、长度筛选，看到喜欢的点下载就导入。非中文的卡可以先翻译，再决定用不用。

自己的模型

DeepSeek、智谱、Kimi、小米 MiMo、Ollama，或任何 OpenAI 兼容接口。填自己的 API Key，按量付费，不经手中转。

长得像聊天软件

气泡或小说排版随你挑；长对话自动摘要、建议回复、替你说一句、消息变体横滑切换，都是为「一直聊下去」准备的。

不止一段故事

同一个角色可以开多段聊天，任意一条消息都能分出新分支；书签、搜索、导出长图和 EPUB 都在。

角色卡生态

兼容 SillyTavern 角色卡、世界书和预设：导入 .png / .json / .charx，世界书按全局、人设、角色、聊天分别绑定。

数据在你手里

没有账号、没有云同步。角色、聊天、设置都存本机，可以打成一个 zip 备份，换手机再还原。

开始用，三步

  1. 装应用下载 APK 安装。第一次安装需要允许「安装未知来源应用」。
  2. 配模型跟着引导挑一家服务商，去官网拿 API Key，粘贴回来点「测试连接」。
  3. 导入角色从角色卡市场挑一张，或者用本地的 .png / .json 文件导入。

轻酒馆本身不带 AI 模型，聊天由你配置的模型服务完成，费用由服务商按用量收取。

常见问题

需要付费吗？

应用本身免费、开源（MIT）。聊天要调用模型，模型服务商按 token 收费；部分服务商有免费额度，本地 Ollama 完全不花钱。

聊天记录会被上传吗？

不会传到我们这里——这个项目没有服务器。只有你发出的对话内容会按需发给所选的模型服务商。

能导入 SillyTavern 的角色卡吗？

可以。V2/V3 角色卡（.png、.json、.charx）、世界书、显示正则、预设都能导入，预设里的提示词顺序也支持在兼容模式里生效。

换手机怎么迁移？

在「设置 → 帮助与关于 → 备份与恢复」里导出 zip，把文件传到新手机再恢复；可以选择只恢复角色卡或只恢复设置。

支持哪些安卓版本？

Android 7.0 及以上（minSdk 24），arm64 手机。
