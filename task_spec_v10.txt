# 轻酒馆 v0.10.0 第六批 — 退出页面后生成不中断（后台继续生成）
（增量。设计沿用克制编辑风。**不与 v0.9 同跑**，等 v0.9 验收后执行。）

## 需求（用户原话）
「我退出对话框如果还没有生成完成不要中断，继续生成」

范围：**单聊 / 群聊 / AI 创建器**三个会话场景全部生效。

## 现状与目标
- 现状：chat_screen / card_creator_screen dispose 时取消 API 流订阅 → 退出即中断，
  已生成部分按现有逻辑处理
- 目标：**用户退出页面后请求继续在后台跑完**：
  - 流式过程持续接收 → 完成后消息**写入存储**（创建器为内存会话，保留于管理器）
  - 用户**返回页面**：看到完整（或仍在继续的）消息，可继续正常交互
  - 返回时若还在生成：UI 重新挂载显示实时增量 + 顶部/输入栏生成态（可停止）

## 实现要求
### 1. 后台生成管理器 `lib/services/active_generations.dart`（新增）
- 单例，按会话 key 管理进行中的生成：`convId`（单聊/群聊）或 `'creator'`
- 结构：`{key: {stream 订阅, 已生成文本缓冲, cancel 句柄, 回调}}`
- **页面 dispose 不再 cancel**：改为「解绑 UI 监听」，请求归管理器持有
- 完成回调：单聊/群聊 → 追加 assistant 消息 + `_save`（错误/中断按现有逻辑保留已生成部分）；
  创建器 → 消息进创建器内存会话缓冲，等待页面重挂载
- 用户在页面内点**停止**：走现有停止逻辑（管理器执行 cancel）
- 同 key 重复进入/重复发送：防重入（已有进行中的生成时不允许再发，与现状一致）

### 2. 页面侧改造
- chat_screen / card_creator_screen：
  - `initState` 时先查管理器有无该 key 的进行中生成 → 有则**接管显示**（继续流式增量）
    并恢复停止按钮/生成态 UI
  - `dispose`：只解绑，不 cancel
  - 从存储加载后与管理器缓冲**合并**（管理器里的追加消息尚未落库的，重进时先落库再展示，
    或展示缓冲+完成时落库——二选一，保证不丢不重）
- 返回页面时的加载时序注意与 v0.8 settle 滚动定位兼容（生成中重进应贴到最新消息）

### 3. 边界（报告里写明）
- App 进程被系统杀死 → 未完成的生成丢失（可接受，创建器内存会话同理）
- App 退后台（HOME）→ Dart isolate 存活期间继续生成，尽力而为，不承诺
- 生成中退出再立刻重进另一会话再回来 → 各 key 互不干扰

## 禁止
- 不改 v0.8/v0.9 行为（自动继续、摘要、压缩、命中率回归全绿）
- 不动 gradle/图标；0 新依赖
- 不做"多条会话同时生成"（管理器允许多 key 并存，但 UI 不提供并行发起入口——
  各页面只管自己的 key）
